# Technical Information

In this section you can find the technical information on how to run the WebComics app on your machine

## Clone and run the project locally

To clone the project locally follow these steps:

1. Install IntelliJ, MySQL 8+ and Tomcat 10+ on your PC;
2. Clone this repo with `git clone` on your command line prompt;
3. Open cloned repository with IntelliJ;
4. Login on MySQL Workbench and open a connection on port 3306 (usually is 3306 by default);
5. Open a new Tomcat configuration with your database options and with the port 8080 for HTTP and 8443 for HTPPS;
6. Set up the ConPool file into the `src/model` folder
7. Open the folder and run the application with the play button on top right on IntelliJ;
8. Open your browser on `localhost:8443` in HTTPS protocol.
